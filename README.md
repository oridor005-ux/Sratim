# מפעל הסרטונים של אורי

כאן נבנים סרטוני הסבר מונפשים, עם קריינות וכתוביות. כל סרטון נמצא בתיקייה נפרדת בתוך `videos/`.

## איך זה עובד

1. קלוד כותב לתיקייה חדשה שני קבצים:
   - `script.json`: התסריט, כלומר רשימת סצנות והטקסט שהקריין אומר בכל אחת, וגם בחירת הקול.
   - `animation.html`: האנימציה עצמה, מצוירת בקוד.
2. ברגע שהקבצים עולים לגיטהאב, מתחילה הרצה אוטומטית ("בניית סרטון") שעושה את הדברים הבאים:
   - מייצרת קריינות בקולות החינמיים של מיקרוסופט,
   - קובעת את אורך כל סצנה לפי אורך הקריינות שלה,
   - מצלמת את האנימציה פריים אחר פריים בדפדפן נסתר,
   - מרכיבה סרטון אנכי של 1080 על 1920, שמתאים לרילס, לטיקטוק ולסטוריז.
3. הסרטון המוכן נשמר בתיקייה `videos/<שם>/out/video.mp4`.

## קולות זמינים

| שם בתסריט | קול |
|---|---|
| `he-male` | גבר, עברית |
| `he-female` | אישה, עברית |
| `en-male` / `en-female` | אנגלית אמריקאית |
| `en-male-uk` / `en-female-uk` | אנגלית בריטית |

אפשר לשנות מהירות דיבור (`rate`, למשל `"+10%"`) וגובה קול (`pitch`, למשל `"-5Hz"`).

## הערות

- הקולות מגיעים משירות ההקראה החינמי של מיקרוסופט, דרך הספרייה `edge-tts`. זה שירות לא רשמי, ואם הוא יפסיק לעבוד יום אחד, אפשר להחליף אותו בשירות אחר בלי לשנות את שאר המערכת.
- לא מחקים קולות של אנשים אמיתיים או של דמויות מוגנות.
- כל הכלים מותקנים רק ממקורות רשמיים: המאגר של אובונטו, המאגר הרשמי של פייתון והדפדפן הרשמי של פלייראייט.

הוראות לקלוד נמצאות בקובץ `CLAUDE.md`.
